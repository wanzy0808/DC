DC Organizer — Master Product Requirements Document (PRD)Document Status: Master Source of TruthRepository: wanzy0808/DC  Brand: DC Organizer  1. Product Definition & VisionDC Organizer adalah platform SaaS pernikahan yang berpusat pada Undangan Pernikahan Digital (Digital Wedding Invitation) dan alur kerja manajemen tamu real-time.  Core Lifecycle:
Wedding Setup → Invitation Creation → Publication → Distribution & Guest Roster → RSVP & Gift Tracking → Guest Management & Seating → QR Ticket → Wedding-Day Check-in → Usher App / Onsite Guest Book  Positioning: DC Organizer bukan sekadar generator undangan digital biasa, melainkan platform manajemen tamu pernikahan digital end-to-end dengan Undangan Digital sebagai pintu utamanya.  2. Technical Stack & Development Principles2.1 StackFramework: Next.js App Router / Turbopack  Runtime: Node.js >= 22 LTS  Package Manager: pnpm >= 11  Language: TypeScript  UI & Styling: Tailwind CSS v4 + Shadcn UI  Animation: Motion via motion/react package  Code Quality: Prettier (Tailwind plugin) + ESLintDatabase & ORM: PostgreSQL + Prisma  Media Engine: Sharp (image processing & cropping)  Canvas Engine: Konva / react-konva (interactive seating & visual editor)  Deployment & CI/CD: Hostinger VPS + GitHub Actions  2.2 Core PrinciplesExtend Over Replace: Pertahankan route, API, UI, dan alur data yang sudah berfungsi kecuali diperintahkan sebaliknya.  Halaman /dashboard dan Beranda harus tetap ada.  Semua UI publik & internal harus menggunakan nama DC Organizer.  Database adalah single source of truth.  Undangan baru harus dimulai dari kondisi kosong (tanpa data default/palsu).  Otorisasi bersifat server-side dan UI gate mencerminkan entitlement server.  3. Arsitektur Data & URL Publik5.1 Onboarding DataMenginput groomName, brideName, dan firstName.  Menyimpan firstName pada User.firstName, serta membuat record WEDDING dan EVENT_KHUSUS.  Nama pasangan di-lock (read-only) pada editor event khusus turunan.  5.2 Canonical Public URLMain Wedding: https://[nama-pasangan][.dcwedding.com/](https://.dcwedding.com/)  Event Khusus: https://[nama-pasangan][.dcwedding.com/](https://.dcwedding.com/)[nama-event]  proxy.ts menangani tenant/event routing ke /invite/[slug]/[eventSlug].  Alias /event-khusus dan /invite/[slug] dipertahankan untuk backward compatibility.  Proteksi password berlaku universal untuk root dan sub-event path.  6. Spesifikasi Fitur Utama6.1 Interactive Seating BuilderVisual 2D berbasis Konva (react-konva).  Database schema: Guest.seatNumber Int? dengan constraint @@unique([tableId, seatNumber]).  Generator Denah: 1–100 meja, 1–50 kursi/meja.  Fitur Drag & Drop ke kursi kosong -> PATCH API.  Drop ke kursi terisi -> Pop-up konfirmasi Tukar Posisi (Swap) / Batal.  Swap posisi kursi berjalan secara atomic via /api/guests/[id]/swap.  Roster tamu seating hanya berisi tamu manual atau tamu RSVP bertipe status ATTENDING.  6.2 RSVP & Guest ManagementMetrik RSVP, filter status, pencarian, dan ekspor CSV.  Pembedaan sumber tamu via enum GuestSource (RSVP vs MANUAL).  Tiket QR dan sistem server-authoritative check-in.  7.
