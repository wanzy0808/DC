# Modern Maroon

Canonical template artwork for the `modern-maroon` invitation theme.

## Art direction

Modern Maroon is a fashion-editorial wedding invitation: deep maroon, warm ivory, dusty rose and champagne accents, with asymmetric portrait placement, oversized typography and magazine-like photo composition. Shared invitation behavior remains in the universal renderer; this folder owns decorative artwork only.

## Artwork

- `01_flower_cascade.webp` — cascading floral accent for RSVP/closing and restrained corner framing.
- `02_flower_cluster.webp` — compact floral accent for event composition.
- `03_arch_frame.webp` — optional architectural frame asset; keep available for Studio/template refinements.
- `04_fabric_wave.webp` — soft fabric movement for greeting/wishes/envelope atmosphere.
- `05_petal_fall.webp` — drifting petal overlay for identity/gallery.
- `06_gold_curve_lines.webp` — champagne linework for cover, identity, date and gift.
- `07_marble_platform.webp` — optional dimensional base asset; keep available for future template-owned compositions.
- `08_minimal_divider.webp` — restrained divider for countdown/editorial transitions.
- `09_watercolor_bg.webp` — low-opacity background texture for envelope and cover.
- `10_leaf_branch.webp` — botanical edge detail for location/closing.

## Rules

- Keep all raster artwork WebP and inside this canonical folder.
- Decorative artwork must stay removable/editable through Studio native-visual targets.
- Do not encode guest, event, RSVP, gift, or other business data into artwork.
- Do not duplicate RSVP, Wishes, Gift, music, or section behavior; those remain shared.
- Default motion must respect section-level animation overrides and reduced-motion preferences.
